Amazon SageMaker AI provides fully managed real-time inference hosting for machine learning models, deploying a model to an endpoint backed by one or more compute instances. This post focuses on the two endpoint architectures most relevant to generative AI workloads with detailed observability: single-model endpoints (SME) and inference component (IC) endpoints.
