AWS announced NVIDIA Nemotron models (Nano 9B v2, Nano 12B v2, Nano 30B, Super 120B) and OpenAI's GPT OSS variants now available on Amazon Bedrock in AWS GovCloud (US), with serverless inference and a zero operator access design. The post details model capabilities, regional availability options, supported service tiers, and code examples for the bedrock-mantle and bedrock-runtime endpoints including tool-calling.
